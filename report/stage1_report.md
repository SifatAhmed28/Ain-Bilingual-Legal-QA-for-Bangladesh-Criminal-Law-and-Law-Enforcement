## Output schema

One JSON object per section in `data/clean/sections.jsonl`. `sec_uid` is the stable join key across languages (`{code}_s{section_no}`, e.g. `pc1860_s302`); the preamble is `{code}_preamble`.

| Field | Meaning |
|---|---|
| `sec_uid` | Stable section id, language-independent |
| `act_id` | bdlaws/BLAD/UKIL act id |
| `act_name` | Official English act name |
| `section_no` | Section number (`302`, `171A`, `preamble`) |
| `title` | Marginal title of the section |
| `text_en` | Official English text, or `null` |
| `text_bn` | Official Bangla text, or `null` |
| `lang` | `en`, `bn`, or `mixed` (both texts present) |
| `repealed` | Always `false` here; repealed sections are dropped |
| `amended` | Latest amendment date/year found in the footnotes, or `null` |
| `footnotes` | Amendment/source notes attached to this section |

Extra columns (`act_name_bn`, `act_year`, `category`, `chapter`, `section_order`, `source_en`, `source_bn`, `source_url`) are added for filtering and provenance.

## Method notes

1. **Section numbers** are recovered from the text in both scripts (`302.`, `১৭১ক।`), with leading footnote markers stripped. Unnumbered rows are merged into the preceding section; preamble rows are kept as `section_no="preamble"`.
2. **Repealed sections** are dropped when their whole text is a Repealed/Omitted note (`[Repealed by ...]`, `[***]`, `রহিত`). Partially omitted sub-sections are kept, as the rest of the section remains in force.
3. **Amendment date** is the latest date/year found in the act's own footnotes (and, for BLAD-only acts, its section text), not the enactment year. It is an indicator, not a legal opinion.
4. **Footnotes** are attached per section using the inline footnote markers (bdlaws `<sup>` numbers; UKIL numbering as fallback).
5. **Sources of record**: bdlaws is current to 2026 and also supplied the repealed flags; BLAD (2025 snapshot) is the offline fallback; UKIL supplies English section names and footnotes. Pages are cached in `data/raw/bdlaws/html`, so re-runs are offline and reproducible.

## Coverage gaps

- Official Bangla text of the colonial codes (Penal Code 1860, CrPC 1898, Evidence Act 1872, Police Act 1861, Arms Act 1878, etc.) is absent from bdlaws/BLAD/UKIL. Their `text_bn` is null by design.
- Official English text of post-1972 Bangla statutes is likewise absent; their `text_en` is null. Bangla queries still reach English sections via cross-lingual retrieval at Stage 2.
- This is a property of the supplied sources, not of the pipeline: a true parallel English–Bangla corpus is not available for these acts.
